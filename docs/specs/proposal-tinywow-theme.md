# OpenSpec Proposal: TinyWow 風格淺色主題改造

**提案人**: CTO

## 一、變更概述

### 1.1 變更類型
- ✅ UI 主題完全改造（深色 → 淺色）
- ✅ 導航架構重構（側邊欄 → 頂部導航）
- ✅ 色彩系統重新定義
- ✅ 組件樣式全面重設計

### 1.2 變更原因
1. **用戶體驗優化**：淺色主題更符合工具類網站的使用習慣
2. **參考業界標準**：TinyWow 等成功產品證明淺色主題的有效性
3. **視覺清晰度提升**：白色背景下圖片處理效果更清晰
4. **品牌形象調整**：從科技感轉向簡潔專業

### 1.3 設計參考
- **TinyWow.com** - 淺色主題、頂部導航、簡潔設計
- **主要特徵**：
  - 白色背景 (#FFFFFF)
  - 藍色主色 (#0ea5e9)
  - 頂部固定導航
  - 簡潔的按鈕和圖示
  - 虛線邊框上傳區域

### 1.4 預期效果
- ✅ 更清晰的視覺層次
- ✅ 更好的圖片處理對比度
- ✅ 更符合一般用戶使用習慣
- ✅ 降低視覺疲勞

## 二、需求分析

### 2.1 核心變更需求

#### A. 色彩系統重構

| 元素 | 現有（深色） | 目標（淺色） |
|------|-------------|-------------|
| 頁面背景 | `neutral-900` (#18181b) | `white` (#FFFFFF) |
| 卡片背景 | `neutral-800/50` (半透明) | `white` (#FFFFFF) |
| 主色 | `primary-500` (#0070f3) | `sky-500` (#0ea5e9) |
| 文字主色 | `neutral-50` (白色) | `neutral-900` (黑色) |
| 文字次要 | `neutral-400` (淺灰) | `neutral-600` (深灰) |
| 邊框 | `neutral-700` (深灰) | `neutral-200` (淺灰) |
| 按鈕主色 | 藍色漸變 + 陰影 | 純藍色 `sky-500` |
| 按鈕次要 | `neutral-800` | `white` + 藍框 |

#### B. 導航架構變更

**現有架構（側邊欄）：**
```
├── NavBar（頂部）
│   ├── Logo
│   └── 語言切換
└── ToolBar（側邊欄，可拖動）
    ├── 去背
    ├── 壓縮
    ├── 裁切
    └── 轉換
```

**目標架構（頂部導航）：**
```
└── Header（頂部固定）
    ├── Logo（左側）
    ├── 工具分類（中間橫向）
    │   ├── 去背
    │   ├── 壓縮
    │   ├── 裁切
    │   └── 轉換
    └── 語言切換（右側）
```

#### C. 組件樣式變更

**C.1 上傳區域（UploadCard）**

現有設計：
- 玻璃擬態卡片（`bg-neutral-800/50 backdrop-blur-xl`）
- 實線邊框（`border-neutral-700/50`）
- 漸變圖示背景
- 深色背景

目標設計：
- 白色卡片（`bg-white`）
- **虛線邊框**（`border-2 border-dashed border-neutral-300`）
- 簡潔藍色圖示
- 實心藍色按鈕 + 白色/藍框次要按鈕

**C.2 預覽區域（PreviewCanvas）**

現有設計：
- 深色卡片背景
- 深色按鈕

目標設計：
- 白色卡片背景
- 藍色實心按鈕
- 增加留白

**C.3 按鈕系統**

現有設計：
```typescript
// 主要按鈕 - 漸變背景
"bg-gradient-to-r from-primary-500 to-primary-600 text-white shadow-lg"

// 次要按鈕 - 深色透明
"bg-neutral-800/50 text-neutral-100 border border-neutral-700"
```

目標設計：
```typescript
// 主要按鈕 - 純色藍色
"bg-sky-500 hover:bg-sky-600 text-white"

// 次要按鈕 - 白色 + 藍框
"bg-white hover:bg-sky-50 text-sky-600 border-2 border-sky-500"
```

### 2.2 非功能性需求

#### A. 性能要求
- 頁面載入速度：< 2s
- 樣式切換流暢度：無閃爍
- 響應式設計：保持現有斷點

#### B. 兼容性要求
- 瀏覽器：與現有相同
- 響應式：保持 Mobile First 設計
- 無障礙：WCAG AA 標準（需重新驗證對比度）

#### C. SEO 要求
- 保持現有 SEO 配置
- 不影響現有頁面結構

## 三、技術方案

### 3.1 檔案變更清單

#### A. 配置檔案

**1. `tailwind.config.ts`**
- 更新主色：`primary` → `sky` 色系
- 更新中性色：調整淺色模式配色
- 移除深色模式陰影（`dark-sm`, `dark-md`, `dark-lg`）
- 調整 light mode 陰影

**2. `app/globals.css`**
- 更新 `:root` CSS 變數（淺色模式為主）
- 移除 `.dark` 類別配置（或標記為未來使用）
- 更新滾動條樣式（淺色）
- 移除玻璃擬態效果（`.glass-card`）

#### B. 佈局組件

**3. `app/[locale]/layout.tsx`**
- 移除 `className="dark"` 強制深色模式
- 更新 `body` 背景色：`bg-neutral-900` → `bg-white`
- 更新文字顏色：`text-neutral-50` → `text-neutral-900`
- 調整 NavBar 和 ToolBar 佈局

**4. `components/NavBar/NavBar.tsx`**
- 重新設計為橫向頂部導航
- 左側：Logo
- 中間：工具分類（橫向排列）
- 右側：語言切換
- 背景：白色 + 淺陰影
- 固定頂部：`fixed top-0`

**5. `components/ToolBar/*`（廢棄或重構）**
- 移除側邊欄（`DesktopToolBar.tsx`）
- 移動端 TabBar 保留或重新設計
- 工具列表移至頂部 NavBar

#### C. 功能組件

**6. `components/features/upload-card.tsx`**
- 移除玻璃擬態樣式
- 改為虛線邊框：`border-2 border-dashed border-neutral-300`
- 背景：`bg-white`
- 圖示背景：純色藍色（`bg-sky-500`）
- 按鈕：實心藍色

**7. `components/features/upload-section.tsx`**
- 調整佈局留白
- 背景：`bg-gray-50`（淺灰背景）
- 內容區域居中

**8. `components/features/preview-canvas.tsx`**
- 白色卡片背景
- 藍色按鈕
- 調整間距

#### D. UI 基礎組件

**9. `components/ui/button.tsx`**
- 更新 `buttonVariants`
- 主要按鈕：純色藍色
- 次要按鈕：白色 + 藍框
- 移除漸變效果

**10. `components/ui/card.tsx`**
- 移除玻璃擬態（`backdrop-blur-xl`）
- 白色背景：`bg-white`
- 淺色邊框：`border-neutral-200`
- 淺陰影：`shadow-md`

**11. `components/ui/input.tsx`**
- 白色背景：`bg-white`
- 淺色邊框：`border-neutral-300`
- 聚焦：`focus:border-sky-500 focus:ring-sky-500/20`
